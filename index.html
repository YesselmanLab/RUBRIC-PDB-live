    Programmatic access

    Each report is a gzipped JSON file on the entries branch:

    https://raw.githubusercontent.com/YesselmanLab/RUBRIC-PDB-live/entries/<ID>.json.gz
    # Python, standard library only
import gzip, json, urllib.request

url = "https://raw.githubusercontent.com/YesselmanLab/RUBRIC-PDB-live/entries/1EHZ.json.gz"
report = json.loads(gzip.decompress(urllib.request.urlopen(url).read()))
print(report["pairs_score"], len(report["pairs"]))

    The same report can be produced locally with pip install rubric-rna and rubric 1EHZ --out.

    Report fields

    pairs_scorePair score of the entry, 0 to 100
    tier_summaryNumber of pairs in each tier
    pairs[]Every base pair: res_id1, res_id2, bp_type, Leontis-Westhof classification, score, tier, num_hbonds, issue_details (issue, severity, tier), geometry and rigid_body parameters, base frames
    backbone_suitenessRUBRIC suiteness of the RNA backbone, 0 to 1
    backbone_residues[]Suites that fit poorly: suiteness, recommendation tier, target_conformer and per-torsion deviations (current and target values)
    pucker_outliers[]Riboses whose pucker from δ and from the P-perpendicular distance disagree
    pucker_unclassified[]Riboses whose δ gives no pucker assignment
    clashes[]Atom pairs within base pairs that overlap, with distance and overlap in Å

    Residue IDs have the form chain-name-number, for example A-G-18.

    About

    RUBRIC classifies the base pairs of an RNA structure in the Leontis-Westhof scheme and scores each pair from 0 to 100 against pairs of the same type and class in high-quality structures. It also assigns each backbone suite to a conformer, suggests target torsions for suites that fit poorly, and flags riboses whose pucker is inconsistent.

    Every Thursday, the day after the weekly PDB release, the update job scores the RNA entries that are new or were revised and removes entries that were made obsolete. When RUBRIC changes, every entry is rescored, so all results come from one RUBRIC version.

    Pair tiers

    Preferredscore 100
    Secondary reviewscore 80 or more, below 100
    Priority reviewscore below 80

    Ambiguous pairs, whose geometry lies between two classes, and pairs involving DNA are not scored.
