# RUBRIC-PDB-live: per-entry reports

This branch holds the full RUBRIC report of every RNA-containing PDB entry, one
gzipped JSON file per entry, named by PDB ID. The report of an entry can be
downloaded directly, for example

    https://raw.githubusercontent.com/YesselmanLab/RUBRIC-PDB-live/entries/1GID.json.gz

The branch is replaced with the current reports at every update, so it holds only
the latest version of each report. The summary table, update log and code are on the
main branch: https://github.com/YesselmanLab/RUBRIC-PDB-live
